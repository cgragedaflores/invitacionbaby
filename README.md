# Invitación Baby Shower - Neitan Jasiel & Xiomara Jhamilet

¡Felicitaciones! Esta es una hermosa invitación digital para la revelación y baby shower de Neitan Jasiel o Xiomara Jhamilet.

## 🚀 Despliegue en Netlify

### Opción 1: Arrastrar y soltar (Más fácil)
1. Ve a [netlify.com](https://netlify.com) y crea una cuenta gratuita
2. Arrastra toda la carpeta `InvitacionBebe` a la zona de "Deploy manually"
3. ¡Listo! Tu sitio estará online en segundos

### Opción 2: Desde Git (Recomendado para actualizaciones)
1. Sube este proyecto a GitHub/GitLab
2. Conecta tu repositorio en Netlify
3. Netlify detectará automáticamente la configuración

## 📁 Archivos incluidos

- `index.html` - Página principal de la invitación
- `style.css` - Estilos optimizados y responsive
- `script.js` - Funcionalidad interactiva
- `bebe1.png` & `bebe2.png` - Imágenes de los bebés
- `netlify.toml` - Configuración de Netlify
- `_redirects` - Reglas de redirección
- `GUIA_USO.md` - Guía de uso

## ✨ Características

- 🎨 Diseño moderno con animaciones suaves
- 📱 Completamente responsive (320px - 1920px+)
- 🎵 Música de fondo opcional
- 💬 Integración con WhatsApp
- 📍 Enlace directo a Google Maps
- 🎭 Animaciones de bebés sobre nubes
- 🔒 Optimizado para performance

## 🎯 Personalización

Para personalizar:
1. Edita `index.html` para cambiar textos, fechas, ubicación
2. Modifica `style.css` para colores y estilos
3. Actualiza `script.js` para cambiar números de WhatsApp
4. Reemplaza `bebe1.png` y `bebe2.png` por tus propias imágenes
